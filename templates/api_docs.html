AI-UX API Documentation

This page documents the available API endpoints for the AI-UX Tester application.

Mandatory Endpoints

/health

  • GET /health/
  • Purpose: Health check for deployment monitoring.
  • Response: {"status": "ok"}

/api-docs

  • GET /api-docs/
  • Purpose: This documentation page.

Functional Endpoints

Landing Page

  • GET /
  • Purpose: Application landing page.

Upload Design

  • GET/POST /upload_design/
  • Purpose: Main interface for design analysis.

Fetch Figma File

  • GET /fetch_figma_file/
  • Purpose: Fetches file data from Figma API.
  • Parameters: file_id, access_token

Generate Heatmap

  • POST /generate_heatmap/
  • Purpose: Runs AI analysis on Figma data to generate UX insights.
  • Request Body: 
    {
  "figma_data": {...},
  "user_prompt": "Optional instructions"
}

Simulation

  • GET /simulation/
  • Purpose: User journey simulation interface.

Design Iteration

  • GET /design_iteration/
  • Purpose: AI design iteration interface.
