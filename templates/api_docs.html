AI-UX API Documentation

Base URL: https://leon4gr45-ux-mentor.hf.space

GET

/health/

Returns the health status of the application.

Response Example:
{ "status": "ok" }
POST

/generate_heatmap/

Generates UX analysis and heatmap data for Figma frames.

Request Payload:
{
    "figma_data": { ... }, // Figma nodes JSON
    "user_prompt": "Optional specific instructions"
}
Response Example:
{
    "heatmap_data": {
        "analysis_data": {
            "NODE_ID": {
                "heatmap": [...],
                "report": "HTML Report",
                "suggestions": [...],
                "ux_score": 85
            }
        }
    }
}
POST

/generate_simulation/

Generates a visual UX simulation script based on prototype interactions.

Request Payload:
{
    "design_data": { "type": "figma", "id": "FILE_ID" },
    "task_description": "User clicks login",
    "access_token": "FIGMA_TOKEN"
}
POST

/generate_iteration/

Generates an improved version of a design to address UX drop-off points.

Request Payload:
{
    "figma_token": "FIGMA_TOKEN",
    "design_data": { "id": "FILE_ID" },
    "dropoff_points": [ { "reason": "Confusing button" } ]
}
